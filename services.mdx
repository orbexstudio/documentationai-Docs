Two plans, depending on how deep you want your server's features to go.

|                           | **Starter Setup** | **Premium Setup** |
| ------------------------- | ----------------- | ----------------- |
| **Price**                 | $10               | $15               |
| **Channels & Categories** | Up to 40          | Unlimited         |
| **Roles**                 | Up to 30          | Unlimited         |
| **Moderation Setup**      | Basic             | Advanced          |
| **Auto Moderation**       | Basic             | Advanced          |
| **Verification Flow**     | Basic             | Advanced          |
| **Logging Flow**          | Basic             | Advanced          |
| **Ticket Flow**           | Basic             | Advanced          |
| **Onboarding Flow**       | Basic             | Advanced          |
| **Free Revisions**        | 1                 | 3                 |
| **Post-Delivery Support** | 1 day             | 3 days            |
| **Delivery Time**         | 1 day             | 3 days            |

> 💡 **What "Basic vs Advanced" actually means:** Take a ticket system as
> an example. The Starter plan includes a simple ticket setup with one
> ticket option and some limitations. The Premium plan includes an
> advanced ticket setup with more options and far fewer limitations. This
> same logic applies across most features in the server.

These tables cover the highlights, but there's simply too much packed into
each plan to list out every single detail here. To make this easier, we've
set up **live preview servers** for both the Starter and Premium setups so
you can join and explore everything yourself before deciding. Invite links
for both can be found in our main [Discord server](https://discord.gg/srar9fFaNT).

Need something fully custom? We also offer **fully custom server builds**
tailored entirely to your vision, with no feature limits and your own
timeline. Reach out via a ticket for a quote.

## Discord Bot Development

Every bot is different, so pricing depends on scope and complexity. Reach
out via a ticket with what you have in mind, and we'll provide a custom
quote.

We can build most things you'd want in a Discord bot using
[BotForge](#what-is-botforge), our framework of choice. If there's
something outside what's currently possible, we'll let you know upfront
before any payment is made.
