## Discord Server Setup

Two plans, depending on how deep you want your server's features to go.

|                                | **Standard Plan**                           | **Premium Plan**                                 |
| ------------------------------ | ------------------------------------------- | ------------------------------------------------ |
| **Price**                      | $4 / 450 BDT / 375 INR                      | $6 / 600 BDT / 560 INR                           |
| **Categories & Channels**      | ✅                                           | ✅                                                |
| **Roles & Permissions**        | ✅                                           | ✅                                                |
| **Server Features**            | Basic version of features                   | Advanced, fully squeezed out versions            |
| **Community Utility Features** | Basic set                                   | Extended set                                     |
| **Best For**                   | Small/growing servers happy with the basics | Larger servers that want every feature maxed out |
| **Free Revisions**             | 1 revision, within 1 day                    | 3 revisions, within 3 days                       |

> 💡 **What "basic vs advanced" actually means:** Take a ticket system as
> an example. The Standard plan includes a simple ticket setup with one
> ticket option and some limitations. The Premium plan includes an
> advanced ticket setup with more options and far fewer limitations. This
> same logic applies across most features in the server.

Need something fully custom? We also offer **fully custom server builds**
tailored entirely to your vision, reach out via a ticket for a quote.

## Discord Bot Development

Bots are priced based on scope and complexity, since every bot request is
different. Reach out via a ticket with what you have in mind, and we'll
provide a custom quote.

We can build most things you'd want in a Discord bot using
[BotForge](#what-is-botforge), our framework of choice. If there's
something outside what's currently possible, we'll let you know upfront
before any payment is made.
