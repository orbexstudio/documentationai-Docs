## What We Do

### 🛠️ Discord Server Setup

Starting fresh? We handle everything — from channel architecture and
permission systems to roles, aesthetics, and onboarding flows. You bring
the vision, we build the foundation.

### 🤖 Discord Bot Development

Need something custom? We develop bots tailored to your server's exact
needs. No bloated public bots, no workarounds — just clean, purpose-built
automation that fits right in.

### 🔍 Discord Server Review & Maintenance

Already have a server but something feels off? We audit what's not working,
fix what's broken, and keep things running smoothly over time. Think of it
as a health check — and a glow-up.
